# LostFound

A polished campus lost-and-found board built with HTML, CSS and vanilla JavaScript.

## Live Demo
https://lost-find-found.netlify.app

## Features
- Campus roll-number login
- Lost and Found item reports
- Image upload and preview
- Urgent item flag
- Search by item, location or category
- Lost / Found filtering
- Category and status filters
- Newest, oldest and urgent sorting
- My Posts dashboard
- Owner-only status updates
- Comments on reports
- Delete your own posts
- Image lightbox preview
- Responsive mobile layout
- Light / dark theme preference
- Local browser persistence with localStorage

## Tech Stack
HTML5, CSS3, JavaScript, Browser Local Storage

## Note
This is a frontend demo. The roll-number login is a local browser identity, not production authentication. A production version could add a backend, database, real authentication, image storage and notifications.
